## sxPanel v0.7.0-Beta

**Custom chat commands**
Create and manage in-game commands straight from the web panel with the new Custom Commands page and editor. Commands can open menu actions, send chat messages, run console commands, or fire server/client events, and they sync to the game with suggestion (autocomplete) support. Console and server-event commands are privileged and need the matching permission. Validation and conflict detection catch clashes with existing commands before you save, and usage is recorded by the system logger.

**Combat logging + Discord integration**
New PvP combat log tracking lethal kills and non-lethal damage summaries (hits, headshots, damage, distance, weapons used), grouped into engagements by a configurable window. Entries flow into the server logger and out to your Discord log channels. A new log batcher groups bursts of combat cards into single messages so busy fights don't trip Discord rate limits. Combat logging can be enabled/disabled and tuned under game features, and only master admins can change those settings.

**Staff tools & developer overlays**
A new set of staff-only in-game tools:

- **Staff Chat** - messages visible only to online staff, shown as toasts.
- **Developer tools** - live coordinates HUD and entity inspector.
- **Invisibility** - toggle to hide yourself from other players.
- **Vehicle cleanup** - delete unoccupied vehicles within a chosen radius.
- **Player management** - send players back to their previous location, or disarm them.

Gated behind new permissions: `menu.devtools`, `menu.delete_entities`, `menu.staffchat`, `players.invisible`, `players.disarm`. Fully localized in all supported languages.

**Freecam / noclip**

- Mouse-wheel speed control with an on-screen speed indicator, with conflicting controls (weapon wheel, radio) blocked while scrolling.
- Speed indicator is localized.
- The slow modifier now always takes precedence over speed boosts, including the scroll boost.
- Particle effects are suppressed when entering or leaving noclip for smoother transitions.

**Tickets**

- Player-related reports now automatically capture nearby players, giving staff investigation context.
- Reporter and target players now include their Discord ID across the database, API, in-game menu and panel.

**Security**

- Mitigated CVE-2026-111497 ("Node2Shell", Brotli decoder out-of-bounds write). The embedded Node runtime is managed by FXServer, so sxPanel now defends itself: requests with `Content-Encoding: br` are rejected with `415`, outbound requests no longer advertise Brotli, and a startup check warns if the embedded Node version is in the affected range.
- Sanitized CSS tokens and theme variables to prevent style injection.

**Discord bot**

- More reliable interaction replies via a shared reply helper that handles deferred, ephemeral and follow-up states, plus an immediate defer to avoid 3-second timeout errors on slow operations.
- Fixed "interaction already acknowledged" (40060) errors when more than one bot instance is running.
- The bot now exits on its own if the panel is unreachable for over 60 seconds, so orphaned bot processes don't linger.
- Command reloads are queued and swapped in atomically, so commands stay available while reloading and overlapping reloads no longer cause duplicate-command errors. Duplicate warnings now name the file of the command that was loaded first.

**Performance**

- Static files are compressed concurrently at startup, using the libuv threadpool better and cutting boot time.
- Fixed file-limit accounting in the static scanner so pending files are counted.

**Fixes**

- `sv_allowlistInstructions` is now cleared when the whitelist is disabled.
- sxPanel no longer overwrites allowlist convars that it manages itself.
- `sv_initialData.lua` no longer runs in monitor mode.

**Changes**

- Per-resource performance telemetry (CPU, memory, tick time) has been removed from the Lua reporter, backend, WebSocket payload and UI. The Resources page now shows "N/A" for these columns.
- The build target is now Node 18.

**Housekeeping**

- Added an `npm run release` script that chains build and packaging.
- Import cleanup, formatting and lint tidy-ups across core, panel and shared.
